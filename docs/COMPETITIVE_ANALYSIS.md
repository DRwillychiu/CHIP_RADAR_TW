## 2. 稀缺性分級

### 🟢 全市場唯一 / 極少數(4 項 — 真本錢)

| # | 功能 | 證據 |
|---|---|---|
| 1 | **29 個命名個人大戶綁分點** | 所有競品都只顯示「凱基台北」「富邦新店」**券商分點代號**。實名大戶名單只在 Smart 商週 / 財訊 / TechNews / 股市老耿 Threads 等媒體文章以**靜態文字列表**存在,**沒有任何競品產品把「蔣承翰=元大新板分點」這種關聯內建到 UI 並動態追蹤** |
| 2 | **T+1 真實 sells 跨日驗證隔日沖** | CMoney 籌碼K線 / Wistock / 大戶投都只提「累計買賣超接近零 + 單日大量 = 疑似隔日沖」這種**啟發式判讀**(用戶肉眼判斷),不是用「今日 buys 榜 × 隔日 sells 榜真實比對」 |

## 4. 誠實判斷 — 稀缺性 **7.5 / 10**

### 為什麼不給 9-10 分

1. 「分點籌碼分析」這個大類別**業界飽和**,免費的 goodinfo / 元大投資先生覆蓋了 60% 散戶基本需求,稀缺的不是類別而是 Chip Radar 的特定切法
2. **「命名大戶」雖然全市場唯一綁進產品,但資料來源是手動維護**(branches.py 的 declared_styles),非演算法自動發現。一旦競品願意花人力標註,**3 個月就能複製**,護城河是「手動勞動 + 圈內知識」不是技術壁壘
3. 派系 Jaccard、時間衰減、策略分層雖罕見,但學術上都是 well-known 演算法,**技術門檻不高**,只是沒人想做散戶看得懂的版本

### 為什麼不給 6 分以下

1. **「實名大戶 × 派系 × T+1 verified × 處置交叉」這 4 個的組合**目前 0 競品做到 — 真實 product-market fit gap
2. **完全免費 + GitHub Pages 自架 + AES 加密前端** — 在收費市場是極稀缺交付模式,光定位就足夠分眾
3. **老闆版 Excel 月檔自動生成 + master 色塊** — B2B 兼容性的隱藏優勢

### 一句話結論

> **Chip Radar 不是「全新發明」級的稀缺,而是「7 項業界普及功能 + 4 項市場唯一切法」的「組合稀缺」**,加上免費自架的交付方式。
>
> **真正的差異化是「命名大戶 + 派系 + verified」三者一起出現在一個免費 dashboard** — 這個組合目前確實沒有第二家。
>
> 護城河可撐 **12-18 個月**;之後要靠**資料新鮮度**與**圈內 know-how** 持續加碼,否則 CMoney 補上就被吃掉。
