## 2. 資料
- 每晚 `scripts/build_daily_summary.py` 產生 `data/daily_summary.json`（和日檔一樣加密）。
- 位置：daily-full 的「Refresh attstock disposal」之後，所以處置名單是當晚的。
- 日檔先經 `filter_day`（已知錯誤的分點日排除，見 `data/quarantine.json`）。
- 讀：最近 12 個日檔（hot + archive）、`stock_history.json`、`disposal_attstock.json`、`stock_categories.json`（官方股名）。
- 內容沒變就不重寫，同一晚重跑不會增加 git 歷史。失敗不擋當晚流程。

## 3. 定義
- **強籌（規則 #1，負責人 2026-10-08 認可）**：同一分點、同一檔股票，近 10 個交易日
  淨買 ≥ 3,000 萬、買超 ≥ 5 天、買超天數 ≥ 賣超天數 × 2.5、累計淨買仍在區間高點 80% 以上；
  同一檔有 ≥ 3 位不同大戶符合才算強籌。只看一般上市櫃股票（4 碼、非 0 開頭）。
- **外資大戶**：分點設定 region 為 us／eu／asia（8 家）。不算進「本土大戶淨買」，另列（負責人 2026-10-09）。
- **本土大戶**：其他追蹤分點，含官股 2 家、公司合計 2 家（9200 凱基證券、9600 富邦證券；負責人 2026-10-09 確認維持在本土）。
- 股名：官方名單優先，亂碼名稱不顯示。
